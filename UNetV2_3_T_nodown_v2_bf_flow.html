UNetV2_3_T_nodown_v2_bf

这是按 lib/models/spconv_unet.py 中 UNetV2_3_T_nodown_v2_bf 的真实前向流程绘制的结构图。
主体是 3-level sparse U-Net：时间维 T 保持不变，只有空间维 H/W 用 stride=(1,2,2) 下采样；MFE=cosv10 时，跳连会先经过增强分支再进入解码器。
Encoder Bottleneck Optional MFE Skip Enhancement Decoder / UR Block 实线: 主路径 虚线: 可选或跳连路径
结构解读：
1. 编码器共有 3 个层级：x_conv1(16)、x_conv2(32)、x_conv3(64)。
2. bottleneck x_bottle 只做通道变换 64 → 128 → 64，不再继续下采样。
3. 解码器使用标准 UR 模式：conv_up_t(skip) → concat(bottom, skip) → conv_up_m → channel_reduction → inverseconv / conv5。
4. 当 MFE == 'cosv10' 时，三层 skip 会分别经过 shortcut + fusion 再送入解码器；否则直接使用原始 skip。
5. 该文件画的是 UNetV2_3_T_nodown_v2_bf，不是运行时默认的 UNetV2_3_T_nodown_v2。
